💡 *My Project:*
**Saathi** — Elderly Medication Companion

🔍 *Problem Statement:*
Elderly Care & Medication Management Platform

🛠️ *What I Built:*
**Saathi** (Hindi for "companion") goes beyond simple pill alarms. It understands *why* elders miss doses — not just forgetting, but 7 distinct reasons: side effects, feeling better, cost/stock issues, swallowing difficulty, fear/beliefs, and more.

**Three AI-powered pillars:**
1. **Kyun Chhoda? (Why Skipped?)** — Voice/text/tap input → AI classifies barrier → Specific action per reason (routine anchoring, doctor alerts, refill reminders, empathy responses)
2. **Doctor Ki Baat (Memory Bridge)** — Paste doctor's words → 5 plain-language lines + draft medicines + overlap warnings across prescriptions
3. **Vrat-Roza-Tyohar Planner** — Per-medicine fasting guidance (with food / empty stomach OK / **ask doctor**) for Navratri, Roza, Ekadashi, Karva Chauth, Paryushan

**Accessibility-first (non-negotiable):**
- 20px base text → A/A+/A++ toggle (24px/28px)
- WCAG AAA contrast mode
- 64px minimum tap targets
- Hindi (Devanagari) + English, instant switch
- Voice input + read-aloud on every screen
- Works offline (deterministic fallbacks, no API key required)
- Human-in-the-loop: AI outputs are drafts, caregiver confirms

💻 *Tech Stack:*
Next.js 16 (App Router) • React 19 • TypeScript (strict) • Tailwind CSS v4 • Google Gemini AI (@google/genai) • Supabase (PostgreSQL) • Zod validation • Vitest (130 tests) • Vercel (deploy)
